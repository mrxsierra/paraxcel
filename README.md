# Paraxcel: DOCX to Excel Converter

## Overview

Paraxcel is a Python application that converts DOCX files containing questions and answers into an Excel format. It provides a user-friendly interface to select files and save outputs efficiently.

pyinstaller --onefile --windowed --icon=src/assets/icon.ico --name=paraxcel src/app.py

## Features

- Read and parse questions from DOCX files.
- Export parsed questions to Excel format.
- User-friendly GUI built with Tkinter.

## Requirements

- Python 3.x
- Required libraries listed in `requirements.txt`

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/paraxcel.git
   ```
